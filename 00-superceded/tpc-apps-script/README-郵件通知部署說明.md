# 改善單郵件通知 — 部署步驟

## 1. 更新 Apps Script

1. 開啟原本的 Apps Script 專案（就是 `GAS_URL` 指向的那個）。
2. 把 `Code.gs` 的內容 **全部刪除**，貼上本資料夾的 `Code.gs`（v4.0，已包含你原本所有功能 + 郵件模組）。
3. 確認第 22 行 `SYSTEM_URL` 是你實際的系統網址（信件底部「開啟系統」按鈕用）。
4. 儲存。

## 2. 重新部署（務必保留同一個網址）

「部署」→「管理部署作業」→ 右上鉛筆 ✏️ →「版本」選 **新版本** → 部署。
> ⚠️ 不要按「新增部署作業」，那會產生新網址，前端就連不到了。

## 3. 重新授權 + 安裝觸發器

新增了寄信權限，必須重新授權一次：

1. 編輯器上方函式下拉選 **`setupMailTriggers`** → 按 ▶ 執行。
2. 跳出授權視窗 → 允許（會要求 Gmail 寄信權限）。
3. 執行紀錄出現「✅ 觸發器已安裝」即完成。

安裝後會有兩個時間觸發器：

| 觸發器 | 時間 | 功能 |
|---|---|---|
| `dailyDeadlineNotify` | 每天 12:00 | 找出「2 天後到期」且未關單的改善單，依工區寄提醒 |
| `weeklyOpenReport` | 每週一 09:00 | 寄出所有未關單彙總報表 |

> Google 時間觸發器有 ±15 分鐘誤差（例如 12:00 可能 12:07 才送出），這是平台限制。
> 專案時區請確認為「(GMT+08:00) 台北」：專案設定 → 時區。

## 4. 在系統中設定收件人

系統 →「⚙️ 設定」→「📧 郵件通知設定」：

- 每個工區各一欄，填該工區收件人（多個以逗號分隔）
  - 台中工區 → Paul, Sean
  - 通霄工區 → Paul, Raymond
- **預設收件人** → Paul（天力工區、其他，以及任何沒填的工區都用這個）
- **每週一 09:00 未關單彙總報表收件人** → Paul, Sean, Raymond
- 填好按 **「☁️ 儲存設定至雲端」**（定時信讀的是雲端設定，一定要存）
- 可按 **「✉️ 寄送測試信」** 確認版型、**「📤 立即寄週報」** 手動觸發一次週報

## 5. 寄信時機總覽

| 時機 | 收件人 | 主旨範例 |
|---|---|---|
| 新增改善單 | 依工區 | 【新增改善單】NCR-042｜通霄工區｜期限 2026-09-05 |
| 狀態改為 Closed | 依工區 | 【改善單已關單】NCR-042｜通霄工區｜… |
| 到期前 2 天 12:00 | 依工區 | 【到期提醒｜剩 2 天】NCR-042｜通霄工區｜期限 2026-09-05 |
| 每週一 09:00 | 週報收件人 | 【每週未關單彙總】2026-09-08｜未關單 4 件（逾期 1 件） |

信件內容皆包含：改善單編號、缺失日期、單位、開單人、工區、缺失項目、關單期限（含剩餘天數徽章）、雲端資料夾連結（可點選按鈕）。

## 6. 注意事項

- 寄件者是**你的 Google 帳號**（Apps Script 以擁有者身分執行）。
- 每日寄信上限：一般 Gmail 100 封／Workspace 1500 封。
- 若要暫停所有通知：設定頁取消勾選「啟用郵件通知」並儲存即可（定時信也會停）。
- `mail-preview.html` / `mail-preview-weekly.html` 是版型預覽用的靜態檔，可直接用瀏覽器開啟查看，與系統運作無關。
