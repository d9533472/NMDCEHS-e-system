# LINE 相簿批次下載工具

直接開啟 `LINEAlbumDownloader.exe`，不需安裝 Python、額外 OCR 套件或輸入 LINE 密碼。

## 操作方式

1. 在 Windows 電腦版 LINE 登入，開啟目標群組的「相簿總覽」。畫面上應同時看得到「相簿／記事本」頁籤，以及相簿名稱、照片張數。
2. 開啟工具，在「LINE 視窗」選擇相簿總覽視窗。聊天視窗不適用；同時有多個 LINE 視窗時，以尺寸及括號內視窗代碼區分。
3. 按「瀏覽資料夾」，選擇所有相簿的儲存位置。
4. 按「① 掃描相簿」。工具會暫時最小化，將 LINE 帶到前景，回到清單頂端並向下掃描。
5. 掃描後請核對**相簿本數、照片張數及資料夾名稱**。OCR 可能誤讀，右側「下載資料夾名稱」可以自行修正。不要把辨識結果視為原名已逐字確認。
6. 按「② 開始下載」。每本相簿使用 LINE 的「儲存全部」，各自建立資料夾。
7. 若要停止，按 **F8**。停止只中止後續自動操作；LINE 已開始的傳輸可能繼續，可在 LINE 自行確認。

掃描及自動操作時，**不要切換其他視窗、移動 LINE、改視窗尺寸，或使用滑鼠**。這是操作電腦介面的工具，不能在背景一邊下載、一邊讓你操作其他軟體。

## 檔案及紀錄

- `2026/10/31下午水車跟水表` 會建立為 `2026_10_31下午水車跟水表`；Windows 不允許的字元會改成底線。
- 同名資料夾加上 `(2)`、`(3)`，不合併、不覆蓋既有照片。
- 每次下載會建立 `LINE下載紀錄_日期時間`，內含 `相簿名稱對照.csv`、`相簿清單.json` 與 `下載紀錄.log`。CSV 保留 LINE 的 OCR 辨識原名及實際資料夾路徑；辨識原名仍可能有 OCR 誤差。
- 下載中的照片位於 `.line-partial-隨機碼` 暫存資料夾。檔案張數達到辨識的張數、檔案非空白且連續穩定約 8 秒後，才改成正式相簿名稱。
- 逾時或停止時保留暫存檔，不當作完成。同一次開啟工具期間可以重試；已確認完成且檔案仍存在的相簿會略過。
- 關閉工具後沒有自動續傳功能，紀錄供查核；下次需重新掃描。未完成的暫存檔可先保留，確認不需使用後自行處理。
- 工具只使用畫面可存取的相簿與 LINE 原有下載功能，不讀取帳密、不解析 LINE 資料庫、不上傳照片或 OCR 圖片。

## 掃描完整性與限制

- 以本機 Windows OCR 辨識名稱、張數，再以封面特徵比對相簿。**相同名稱、相同張數且封面近乎相同的相簿，可能被視為同一本**；請務必核對清單本數。
- 如果無法讀取捲軸的底部位置，會顯示「畫面連續未變動，但無法讀取捲軸底部」。這代表未證實完整，請核對後再下載。
- 這個版本配合目前看到的單欄、逐本往下捲動的 LINE 相簿總覽。LINE 更新或版型、語言變更，可能需要調整。
- 網路較慢可提高「換頁等待」及「每本下載上限」。相簿照片尚未載入、下載失敗、張數辨識錯誤時，工具會停止或逾時；不要把已建立資料夾視為所有照片均成功。
- 工具不處理登入、驗證碼或權限提示。請先在 LINE 完成登入。

## 驗證與來源

`self-test-result.txt` 記錄純程式測試；介面、相簿掃描及實際下載是否完成實測，另記於 `驗證狀態.txt`。程式編譯成功不代表你的所有群組皆可批次下載。

- LINE 官方相簿說明：https://help.line.me/line?contentId=20000248
- Windows OCR：https://learn.microsoft.com/en-us/uwp/api/windows.media.ocr.ocrengine.recognizeasync
- Windows UI Automation：https://learn.microsoft.com/en-us/windows/win32/winauto/uiauto-obtainingelements

開發檔為 `LineAlbumDownloader.cs`、`app.manifest` 及 `build.ps1`。重新編譯需要 Windows 的 C# 編譯器及 .NET Framework 參考組件；直接執行 EXE 不需重新編譯。
