# LINE 相簿批次儲存（LineAlbumSaver.exe）

直接執行 `LineAlbumSaver.exe`，全部在本機跑（Windows 內建 OCR），不連網、不吃 token。

## 使用步驟
1. 在電腦版 LINE 打開群組的「相簿」總覽，捲到要開始的那一本。
2. 開工具 → ① 選視窗：名稱後面寫「相簿」的才是總覽（例如「台中水車 相簿」）；一般對話視窗會標「（一般對話視窗）」，不能選來執行。
3. ② 選儲存資料夾（會記住上次的位置）。
4. 按「▼ 逐步往下掃描並儲存」。工具會縮小，從目前捲軸位置往下逐本：點名稱 → 單本相簿右上 ⋮ → 儲存全部 → 自動填入子資料夾 → 等檔案存完 → 關掉單本視窗 → 下一本，捲到底自動停止。
5. 執行中不要動滑鼠鍵盤，**F8** 隨時停止。

## 核對機制
- 每本讀單本相簿上的「N張照片」，存完後數資料夾內的檔案數比對：綠＝相符、紅＝不完整/失敗。
- 結束時在儲存資料夾產生 `LINE相簿下載核對_日期時間.csv`。
- 「重新核對張數」可隨時重新數一次並另存核對表；雙擊表格列開啟該資料夾。
- 資料夾已存在且張數相符 → 自動略過；不符 → 另建 `名稱 (2)` 重新下載。

## 技術備註
- 視窗類型用 UI Automation 類別判斷：`GroupHomeWindow`＝相簿總覽、`AlbumDetailWindow`＝單本相簿、`LcContextMenu`＝⋮ 選單、`ChatWindow`＝對話視窗。
- 總覽捲軸用 RangeValue 直接設定，並用捲軸值換算每本相簿的絕對位置，避免重複或漏掉。
- `LineAlbumSaver.exe --probe 輸出.txt`：只讀不點，列出視窗判斷與畫面上的相簿名稱/張數/選單辨識結果。
- 重新編譯：`powershell -File build.ps1`。
